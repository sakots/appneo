# appneo

最新のneoをふたばお絵かきで使いたい

## 使い方

ブックマークレットとして以下を実行したのち、お絵かきボタンを押してください

```javascript
javascript:(function(){const s=document.createElement('script');s.charset='UTF-8';s.src='https://neo.sakots.net/appneo.js?'+Date.now();document.head.appendChild(s);})();
```
